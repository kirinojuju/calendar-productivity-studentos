# Calendar: อ่านโค้ดจากงานที่อาจารย์กำหนด

งานหลักคือ **สร้าง appointment แล้วเปลี่ยนวันของ appointment ได้** ส่วน Courses, reminders และหน้าอื่นเป็นฟีเจอร์ที่เพิ่มเพื่อพัฒนา StudentOS ต่อ

## ลำดับการทำงาน

1. กด **New event** แล้วกรอกชื่อ วันที่ เวลาเริ่ม และเวลาสิ้นสุดใน `EventEditor` ที่ `src/pages/CalendarPage.jsx`
2. ฟังก์ชัน `submit` ตรวจว่าเวลาสิ้นสุดต้องหลังเวลาเริ่ม แล้วส่งข้อมูลให้ `saveEvent`
3. `saveEvent` เรียก `actions.addEvent` สำหรับรายการใหม่ หรือ `actions.updateEvent` สำหรับรายการที่แก้ไข
4. ปฏิทินแสดงรายการจาก `workspace.events` โดยใช้วันที่ของแต่ละรายการ
5. เมื่อลากรายการไปยังวันอื่น `CalendarMonth` ส่ง ID ของรายการและวันปลายทางให้ `moveEvent`
6. `moveEvent` หารายการตาม ID แล้วเรียก `actions.updateEvent(id, { date: day })` จึงเปลี่ยนเฉพาะวันที่

`actions.addEvent` และ `actions.updateEvent` อยู่ใน `src/context/WorkspaceContext.jsx` ซึ่งดูแลข้อมูลของแอปและการบันทึก ส่วน `CalendarMonth` ใน `src/components/CalendarMonth.jsx` วาดช่องแต่ละวันและรับการลากวาง

## ถ้าต้องสาธิตงานหลัก

สร้าง appointment ชื่อ "พบอาจารย์" ในวันหนึ่ง จากนั้นลากไปอีกวัน และเปิดรายการขึ้นมาเพื่อดูว่าวันที่เปลี่ยนแล้ว ลองรีเฟรชหน้าเพื่อตรวจว่าข้อมูลยังอยู่ด้วย

ถ้าต้องอธิบายบทบาทในการทำงาน ให้บอกตามจริงว่าคุณออกแบบความต้องการและหน้าตาของแอป ส่วนการเขียนโค้ดมีเครื่องมือช่วย แล้วอธิบาย flow ข้างบนจากสิ่งที่คุณเข้าใจและทดสอบเอง
